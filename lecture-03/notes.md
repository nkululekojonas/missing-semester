# Lecture 03: Vim

## Key Concepts
- Vim: Modal Editor meaning it has different modes
  - Insert
  - Visual
  - Replace
  - Command

- You can switch between modes using different command, the idea is that when your programming, you spend your time doing different things.
- You start in Normal mode, from there you can navigate to modes like Insert <i>, Command <:> and Visual <Ctrl-v, Shift-V, v>.
- The biggest take away is that vim is a programming language, and so you can combine and build different ways of doing things.
